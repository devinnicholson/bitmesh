# Support

Bitmesh is pre-1.0 research software.

Use [GitHub Discussions](https://github.com/devinnicholson/bitmesh/discussions)
for usage questions and design discussion. Use
[GitHub Issues](https://github.com/devinnicholson/bitmesh/issues) for
reproducible defects, documentation problems, and narrowly scoped feature
requests.

Before filing an issue:

1. Reproduce it on a supported Rust toolchain with `cargo test --locked`.
2. Record the Bitmesh commit or release and operating system.
3. Reduce certificate or board inputs to the smallest case that still fails.
4. State which documented guarantee or API behavior is affected.

Security-sensitive reports follow [SECURITY.md](SECURITY.md). Questions about a
research result, unpublished experiment, or Partizan paper are outside this
repository's support scope.
